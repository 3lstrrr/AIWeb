# 评审体验说明

## 一、是否需要登录

**默认不需要**：项目没有用户体系，打开链接即可使用（单用户演示态，所有数据在同一份 Supabase 里）。

**但强烈建议开启访问口令**，原因很实际：

- 公开地址一旦被爬虫或他人拿到，`/api/ingest`、`/api/embed`、`/api/quiz`、`/api/graph` 会被直接调用，**消耗你的智谱额度**；
- `/api/documents/:id` 的 DELETE 与 `/api/conversations/:id` 的 DELETE 没有二次鉴权，任何人都能删数据；
- 评委演示时若有人并行操作，数据会被改乱。

项目已内置可选的 **HTTP Basic 认证**（`middleware.ts`），配置两个环境变量即生效，**不改一行代码**：

| 变量 | 示例 |
| --- | --- |
| `BASIC_AUTH_USER` | `zhixue-review` |
| `BASIC_AUTH_PASSWORD` | `Zx-2026-demo`（建议 12 位以上，别用纯数字） |

两项都填才生效；留空即全站公开。生效后：

- 浏览器首次访问会弹出账号密码框（原生弹窗，无需登录页）；
- 所有 `/api/*` 请求同样受保护，前端代码无需改动（浏览器会自动带上凭据）；
- `/icon.svg`、`/opengraph-image` 保持公开，保证分享卡片与图标正常。

> 另一个选择是 Vercel 自带的 **Deployment Protection**（Settings → Deployment Protection → Vercel Authentication / Password Protection），效果类似但只对 Preview/Production 生效且无法被 curl 便捷验证。二选一即可，**别同时开**，否则评委要过两道口令。

## 二、如何把账号给评委

推荐做法（三步，1 分钟）：

1. Vercel → 项目 → **Settings → Environment Variables** 添加 `BASIC_AUTH_USER` / `BASIC_AUTH_PASSWORD`；
2. **Deployments → 最新一次 → Redeploy**（环境变量改动需要重新构建）；
3. 在提交材料 / 答辩 PPT 的「在线体验」页写：

   ```text
   在线体验：http://8.137.96.36:8088
   访问账号：见提交材料
   访问口令：见提交材料
   （首次打开若弹出浏览器账号密码框，输入上述两项即可）
   ```

> 若不想开保护：直接给地址即可，但请把 `BASIC_AUTH_*` 留空并在答辩时说明「演示环境为公开访问」。

## 三、评委 5 分钟体验路线

| 步骤 | 操作 | 看点 |
| --- | --- | --- |
| 1（30 秒） | 打开首页，直接提问「什么是梯度下降」 | 逐字流式输出；句末 `[1][2]` 角标；回答下方「引用来源」卡片 |
| 2（30 秒） | 点任意角标 / 来源卡片 | 右侧 PDF 跳到对应页并**黄底高亮**片段（移动端自动展开查看器） |
| 3（1 分钟） | 侧栏「📝 AI 出题」→ 选文档 → 5 道单选题 → 开始出题 | 可折叠「思考日志」展示两次工具调用；作答后即时判分 + 解析 + 引用 |
| 4（1 分钟） | 侧栏「🕸️ 知识图谱」→ 选文档 → 生成图谱 | SVG 力导向图；节点可拖拽；点击节点只高亮相连边；二次打开秒出（缓存） |
| 5（可选） | 侧栏「📄 文档管理」→ 上传自己的 PDF | 解析→向量化→就绪全流程与进度条 |

## 四、演示前预热清单（重要）

评委不会等你跑 30 秒的向量化，请提前做好：

- [ ] 至少上传 **1 份文本型 PDF** 并等到状态「就绪」（建议 10–30 页、带清晰小标题的课件）
- [ ] 在「知识图谱」里对这份文档**生成过一次**（结果已写入 `graph_json`，评委点击秒开）
- [ ] 在聊天页问过 2–3 个问题，确认角标与 PDF 定位正常（尤其确认 PDF 是文本层而非扫描件）
- [ ] 确认线上额度充足：智谱控制台看下当日调用量
- [ ] 准备**离线兜底**：本地 `npm run dev` + 一段 60 秒录屏，网络不稳时不至于冷场

## 五、已知限制与建议口径

| 限制 | 建议说法 |
| --- | --- |
| 无用户体系，数据不隔离 | 「演示版为单用户态；表结构已按 `conversation_id`/`document_id` 设计，接入 Supabase Auth 后加 RLS 即可多租户」 |
| 刷新页面不回填历史消息 | 「会话与消息已落库（`messages` 表可查），历史回填是下一步迭代项」 |
| 扫描版 PDF 无法解析 | 「当前用 pdf-parse 抽文本层；扫描件需接 OCR（如 PaddleOCR），属于已知边界」 |
| Vercel 单请求 4.5 MB | 「大文件需改 Storage 直传 + 队列式向量化，本地自托管不受此限」 |
| 出题/图谱耗时 10–40 秒 | 「两个接口都是多步 Agent/单次大模型调用，已设 120s 超时并做了缓存（图谱）」 |
| 敏感词与注入拦截是规则匹配 | 「三道防线：规则拦截 + 精确模式只依据 context + 输出兜底；规则表可扩展」 |
